# CodeReview Agent

AI-powered code review assistant built with MiMo V2.5.

## Features

- IDE-like dark theme interface
- Syntax-highlighted diff viewer with line numbers
- Inline review comments with severity badges (Critical, Warning, Info, Suggestion)
- File tree navigation
- Review summary statistics

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- No external dependencies or frameworks

## Usage

Open `index.html` in a browser to explore the code review dashboard with sample code diffs and AI-generated review comments.

## AI Engine

Powered by **MiMo V2.5** — Nous Research's code review and analysis model.
